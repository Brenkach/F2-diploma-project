| Параметр | Значення |
|---|---|
| Стандарт | ISO/IEC/IEEE 29148:2018 |
| Версія | 1.0 |
| Дата | 2026-10-28 |

**Умовні позначення.** Слово «повинна» позначає обов'язкову вимогу. Кожна вимога має унікальний індекс і перевіряється способом, наведеним у розділі 4.

## 1. System Context (Контекст системи)

### 1.1. Призначення та межі (Scope)

Система «Сусід» є веб-платформою для пошуку та замовлення локальних послуг (ремонт, електромонтаж, репетиторство, догляд за тваринами) з районним рейтингом довіри, стійким до накрутки відгуків.

**У межах системи:** реєстрація та автентифікація; профілі майстрів і каталог; життєвий цикл замовлення; відгуки; обчислення рейтингу довіри; виявлення накруток; попередня діагностика запиту за фото; сповіщення та взаємодія через Telegram-бота; модерація та статистика.

**За межами системи:** онлайн-оплата та ескроу; ведення договорів; мобільні застосунки; геолокація за GPS; автоматичне видалення відгуків без рішення модератора.

### 1.2. Актори

| Актор | Опис |
|---|---|
| Замовник | Мешканець району; шукає майстра, створює запит, підтверджує виконання, залишає відгук |
| Майстер | Виконавець; веде профіль, приймає запити, позначає виконання |
| Модератор | Перевіряє документи, скарги та підозрілі відгуки; блокує акаунти |

### 1.3. Зовнішні системи та інтерфейси

| Система | Інтерфейс | Призначення |
|---|---|---|
| Telegram Bot API | HTTPS | Сповіщення, вхід через Telegram Login, передача контакту для верифікації телефону |
| Вебпереглядач користувача | HTTPS | Доступ до вебзастосунку |

### 1.4. Обмеження та припущення

| Ідентифікатор | Обмеження |
|---|---|
| CON-01 | Розгортання на одному вузлі (4 vCPU, 8 ГБ RAM, SSD) за допомогою Docker Compose |
| CON-02 | Усе програмне забезпечення безкоштовне; ML-моделі відкриті та виконуються локально |
| CON-03 | Верифікація телефону виконується через контакт Telegram, SMS-шлюз не використовується |
| CON-04 | Дані для оцінки алгоритмів виявлення накруток синтетичні |

### 1.5. Нормативні посилання

Закон України «Про захист персональних даних» № 2297-VI; Regulation (EU) 2016/679 (GDPR); OWASP Top 10:2021; RFC 7519 (JWT); ISO/IEC 25010; Telegram Bot API; OpenAPI Specification 3.x.

## 3. Non-Functional Requirements (Нефункціональні вимоги)

Цільовий вузол: 4 vCPU, 8 ГБ RAM, SSD, Docker Compose. Значення є цільовими й підлягають підтвердженню в Розділі 3.

### 3.1. Продуктивність

| ID | Вимога |
|---|---|
| <a id="srs-nfr-perf-01"></a>SRS-NFR-PERF-01 | Запит каталогу з Redis cache повинен мати Latency p95 ≤ 200 мс при 200 RPS протягом 10 хв. |
| <a id="srs-nfr-perf-02"></a>SRS-NFR-PERF-02 | Текстовий пошук (pg_trgm, без cache) повинен мати Latency p95 ≤ 400 мс при 50 RPS. |
| <a id="srs-nfr-perf-03"></a>SRS-NFR-PERF-03 | Операції запису (створення замовлення, зміна статусу) повинні мати Latency p95 ≤ 500 мс при 20 RPS. |
| <a id="srs-nfr-perf-04"></a>SRS-NFR-PERF-04 | Частка відповідей 5xx повинна бути менше 1 % у сценаріях PERF-01…PERF-03. |
| <a id="srs-nfr-perf-05"></a>SRS-NFR-PERF-05 | За зростання навантаження на запит каталогу з 0 до 500 RPS за 30 с частка помилок на піку повинна бути менше 5 %, а Latency p95 повинна повернутися до 200 мс не пізніше ніж через 60 с після спаду. |

## 5. Glossary (Глосарій)

| Термін | Визначення |
|---|---|
| Transactional Outbox | Патерн, за якого подія записується в таблицю тієї самої СУБД у транзакції зі зміною стану, а окремий процес публікує її в брокер |
| Idempotency (ідемпотентність) | Властивість обробника, за якої повторна обробка тієї самої події не змінює результат |
| Bayesian smoothing (байєсівське згладжування) | Метод зваженого середнього з апріорною оцінкою, що зменшує вплив малої кількості спостережень |
| Sybil attack | Атака, за якої одна особа створює кілька акаунтів для впливу на рейтинги чи голосування |
| Latency p95 | Значення часу відповіді, яке не перевищують 95 % запитів |
| JWT | JSON Web Token: підписаний токен для передачі тверджень про користувача (RFC 7519) |
| Zero-shot classification | Класифікація за текстовими описами класів без навчання на розмічених прикладах цільової задачі |
