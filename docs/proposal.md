# Веб-платформа локальних послуг «Сусід» із районним рейтингом довіри

# "Сусід" Local Services Platform with a District-Based Trust Rating

## 1. Актуальність та проблематика

Пошук виконавців побутових послуг (сантехніки, електрики, репетитори, догляд за тваринами) здійснюється переважно через знайомих та чати будинків. Такий підхід не забезпечує гарантій, верифікації виконавців і збереження історії замовлень. Загальні дошки оголошень містять значний обсяг спаму, а відгуки на них піддаються штучному накрученню.

Технічна складність полягає в побудові рейтингу, стійкого до маніпуляцій, який враховує
верифікацію виконавця, географічну близькість авторів відгуків, кількість підтверджених
замовлень та давність активності.

## 2. Ідея продукту та тип архітектури

Веб-застосунок із Telegram-ботом для пошуку та замовлення локальних послуг.
Архітектура: модульний моноліт (Flask) з виділеним шаром асинхронних воркерів
(Celery) для перерахунку рейтингу та доставки сповіщень; реляційна модель даних
на PostgreSQL; REST API з OpenAPI-специфікацією.

## 3. Core Features

1. Рольова модель доступу (RBAC): замовник, майстер, модератор; автентифікація, вхід через Telegram.
2. Профілі майстрів: послуги, ціни, портфоліо, район обслуговування.
3. Каталог із повнотекстовим пошуком та фільтрацією за категорією й районом.
4. Життєвий цикл замовлення на основі скінченного автомата (створено → прийнято → виконано → підтверджено замовником).
5. Відгуки, доступні лише після підтвердженого замовлення.
6. Алгоритм рейтингу довіри: ваги за верифікацією, районом автора відгуку, кількістю підтверджених
замовлень і давністю активності; виявлення підозрілих патернів відгуків; асинхронний перерахунок.
7. Модерація: система скарг, верифікація телефону та документів, панель адміністратора зі статистикою.

## 4. Технологічний стек

- **Мови програмування:** Python 3.12, SQL
- **Архітектурні патерни:** модульний моноліт, State Machine, Repository, асинхронні задачі (Task Queue), RBAC
- **Фреймворки та бібліотеки:** Flask, SQLAlchemy, Alembic, Celery, Flask-Smorest (OpenAPI), aiogram (Telegram Bot API), Jinja2 + HTMX
- **Бази даних:** PostgreSQL (повнотекстовий пошук, pg_trgm), Redis (брокер черги та кеш)
- **Тестування та якість:** pytest, SonarQube, k6
- **DevOps-інструменти:** Docker, Docker Compose, GitHub Actions (CI/CD), Trivy, Prometheus, Grafana, Nginx
- **Розгортання:** хмарний VPS
